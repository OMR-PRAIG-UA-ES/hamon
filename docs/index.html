HAMON

Harmony Model and Notation

A universal, lossless harmony-label interlingua — one typed model for chord symbols, Roman numerals, Nashville numbers, figured bass and functional analysis, round-tripped across MEI · MusicXML · Humdrum · LilyPond · ABC · MuseScore · Harte · iReal Pro · DCML · RomanText · Dezrann.

ICCCM'26 →

Representative examples exported to every encoding, an interactive loss viewer, and the poster figures.

Use it →

Install the library and convert harmony between encodings, in three commands.

Fixtures →

The conformance corpus, browsable — each case realized as a real score and shown in every encoding.
